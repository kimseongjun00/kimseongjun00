## 🏗 Building

### 짐캉스 (Gymcance) &nbsp;—&nbsp; [gymcance.com](https://www.gymcance.com)

> 정기권 없이 원하는 날만 결제하는 **운동시설 일일권 통합 플랫폼**

정기권 하루 환산가 2,000원 vs 현장 일일권 20,000원 — 10배 차이가 만든 구조적 불합리함을 코드로 해결했습니다.

| | |
|---|---|
| 📱 **React Native App × 2** | 이용자 앱 + 운영자 앱 직접 개발. QR 체크인, 예약·결제 플로우 |
| ⚙️ **Spring Boot API** | JWT 인증, Toss PG 결제, WebSocket 실시간 문의, Docker 운영 |
| 🌐 **Web × 3** | 랜딩(gymcance.com) + 파트너 콘솔(admin) + 플랫폼 어드민 |
